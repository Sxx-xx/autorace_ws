# C920 차선 카메라 거치대 (E1)

라이다 뒤에 기둥을 세우고, 팔을 라이다 위로 뻗어 렌즈를 바퀴 축 2 cm 앞,
바닥에서 약 25 cm 높이에 51° 숙여 둔다.

```
gen_camera_mount.py        FreeCAD 스크립트 (치수는 맨 위 상수, MEASURE 표시는 실측해서 고칠 값)
export/E1_camera_mount.stl 슬라이서용 (출력 자세 그대로: 옆면이 바닥, 서포트 없음)
export/E1_camera_mount.step 로봇 좌표 그대로의 CAD 파일
export/geometry.txt        렌즈 위치·시야·간섭 점검, yaml 에 넣을 카메라 값
```

다시 만들기: `cd hardware/camera_mount && freecadcmd gen_camera_mount.py`

## 왜 이 모양인가

- 카메라를 로봇 뒤에 낮게 달면 윗판 앞 모서리가 가까운 바닥을 가린다.
  0.10 m 앞 바닥을 보려면 렌즈가 0.48 m 높이여야 한다.
- 라이다는 자기 높이의 수평면만 잰다. 그 위를 지나는 팔은 가리지 않고,
  기둥은 라이다 바로 뒤 몇 도만 가린다. 미션은 라이다의 앞과 옆만 쓴다.
  기둥이 스캔에 잡히면 `ld_lidar` 의 `range_min` 을 0.08 로 올린다.
- 렌즈가 라이다보다 앞에 있으므로 라이다는 화면에 들어오지 않는다.

## 출력과 조립

- PLA, 벽 4줄, 채움 30 % 이상. STL 자세 그대로 (옆면이 바닥).
- 볼트: 발에 M3 × 10 두 개와 너트 (윗판 구멍 아래에서 너트), 카메라에
  1/4-20 × 1/2" (13 mm) 카메라 나사 하나.
- 순서: 카메라를 먼저 받침에 고정한다 (아래에서 1/4" 나사, 라이다 위 틈이 좁다).
  그다음 거치대를 윗판에 놓고, 팔에 뚫린 구멍으로 드라이버를 넣어 M3 를 조인다.
- 카메라 머리 각도는 책상에 세웠을 때의 기본 자세(집게를 접은 상태)로 둔다.
  받침이 51° 기울어 있어 그 자세로 51° 숙여진다.
- 단 뒤 실제 높이·각도는 바닥 테이프로 보정해서 `perception_real.yaml` 의
  `camera.*` 에 넣는다 (geometry.txt 의 값은 설계값).
