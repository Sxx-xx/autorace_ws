# 연습 경기장 소품 — 3D 프린팅 모델

오토레이스 코스의 소품을 실물로 만들기 위한 부품 모음이다. 치수는
`src/autorace_sim`의 시뮬레이션 모델을 따르므로, 여기서 만든 소품으로 연습하면
시뮬에서 맞춘 인식 파라미터가 그대로 쓰인다 (다른 점은 맨 아래 표).

```
gen_venue_parts.py    FreeCAD 스크립트. 모든 부품을 만들고 STL/STEP/FCStd 로 내보낸다
make_sign_faces.py    표지판 스티커 원고 (시뮬 텍스처 → 실물 크기 PNG, A4 PDF)
export/stl/           슬라이서에 넣을 파일 (출력 자세 그대로, 바닥면 z = 0)
export/step/          치수를 고칠 때 CAD 로 여는 파일
export/venue_props.FCStd  FreeCAD 문서 (부품 전부)
export/parts.md       부품 표 (번호·수량·크기·무게) — 스크립트가 만든다
signs/                표지판 얼굴 PNG(300 dpi) 와 sign_sheet_A4.pdf
export/preview/       부품 미리보기 그림 (raster.py 가 STL 을 렌더링)
firmware/             아두이노 스케치: traffic_light/, level_crossing/ (Mega 2560)
```

다시 만들기:

```bash
cd hardware/venue_props
freecadcmd gen_venue_parts.py      # 1~2 분, FreeCAD 0.21
python3 make_sign_faces.py         # Pillow 필요
python3 raster.py export/preview/C_level_crossing.png export/stl/C*.stl   # 미리보기 그림
```

치수를 바꾸려면 스크립트 윗부분의 상수(`TL_*`, `LC_*`, `BAR_*`, `CP_*`)를 고치고
다시 실행한다. 손으로 STL 을 고치지 말 것.

## 부품 표

[export/parts.md](export/parts.md) 가 정식 표다. 조립 단위로 묶으면:

| 조립 | 부품 | 비고 |
|---|---|---|
| 신호등 | A1 모듈 ×3, A7 차양 ×3, A2 뒷판 ×3, A3 윗덮개, A4 발판, A5 램프 컵 ×3, A6 LED 판 ×3 | 메가 1 |
| 차단바 | C1 기둥, C2 발판, C3 허브, C4 바 토막 ×5, C5 끝 토막, C6 꼬리, 센서 기둥 ×2 (C7 **또는** C8) | 아두이노 1, 서보 1, 센서 2 |
| 컨트롤러 박스 | B1 박스, B2 뚜껑 | 신호등·차단바 각 1 → 2 세트 |
| 표지판 7 | D1 받침 ×7, D2 원판 ×2, D3 팔각 ×1, D4 삼각 ×3, D5 사각 ×1 | 스티커는 signs/ |
| 공사 기둥 3 | E1 띠 반쪽 ×8, E2 이음 ×4, E3 윗덮개 ×2 — **기둥 하나 분량**. 3개면 ×3 | 흑/백 번갈아 |
| 터널 장애물 | F1, F2 ×2, F3 | 종이 상자로 대신해도 된다 |

전체 약 3.2 kg (공사 기둥 1개·터널 장애물 포함). 공사 기둥 3개를 다 뽑으면 +1.1 kg.
공사 기둥과 터널 장애물은 라이다에 잡히기만 하면 되므로 우드락·종이 상자에 흑백
테이프를 감아도 같다. 필라멘트가 아까우면 그쪽을 권한다.

## 출력 설정

- PLA, 0.2 mm 층, 노즐 0.4, 벽 3줄(1.2 mm), 채움 15 %. 얇은 껍데기 부품은 벽이 곧 두께라 채움률은 무게에 거의 영향이 없다.
- 서포트 **없음**. 모든 부품은 내보낸 자세 그대로 놓으면 된다.
  - A1 모듈은 앞면이 바닥. 뒷면(개방)이 위.
  - A5 램프 컵은 렌즈가 바닥. 플랜지가 3 mm 튀어나오는 작은 오버행이 있는데 하우징 안쪽이라 처져도 상관없다.
  - C1 기둥(212 mm)·D1 받침(142 mm)은 길쭉하니 브림을 켠다.
  - C3 허브는 소켓 천장이 47 mm 다리(브리지)다. 보통 프린터는 그냥 된다.
- 색: A5 램프 컵은 **투명 PETG 또는 흰색**(빛이 통과해야 한다), 나머지 신호등은 검정. 바 토막(C4/C5)은 검정·흰색을 번갈아 출력하면 칠할 필요가 없다. 공사 기둥 띠(E1)도 띠마다 색을 바꾼다 (아래부터 흰-검-흰-검, 시뮬과 같음).
- 끼워 맞춤 틈새는 한쪽 0.3 mm(`CLEAR`). 헐거우면 0.2, 빡빡하면 0.4 로 바꿔 다시 생성.
- 핀 구멍은 Ø2.9: 3 mm 필라멘트 토막(길이 20) 이나 M3 나사를 박는다.

## 신호등 조립과 배선

```
        [A3 윗덮개]
        [A1 모듈 + A7 차양 + A5 컵 + A6 LED판 + A2 뒷판]  ← 녹
        [A1 ...]                                          ← 황
        [A1 ...]                                          ← 적
        [A4 발판] ── 밑면 홈으로 케이블 ──→ [B1 컨트롤러 박스]
```

1. A6 LED 판에 LED 를 꽂고(가운데 Ø10 하나, 또는 Ø5 세 개) 다리를 뒤로 뺀다. A5 컵 안쪽 끝에 밀어 넣는다.
2. 컵을 모듈 **안쪽에서** 앞면 구멍으로 밀어 넣는다. 렌즈가 앞면과 나란해지고 플랜지가 안쪽에 걸린다. 순간접착제 한 방울.
3. A7 차양을 앞면의 반원 홈(램프 위쪽)에 끼워 붙인다.
4. 모듈 세 개를 핀(필라멘트 토막)으로 쌓는다. 위아래 벽 가운데 50×26 통로로 전선을 내린다.
5. 맨 아래 모듈은 A4 발판 위 핀 구멍에 꽂는다. 전선은 발판 가운데 Ø10 구멍 → 밑면 홈 → 뒤쪽 가장자리로 나와 박스까지 바닥을 따라간다.
6. 뒷판 A2 를 M3 ×8 나사 4개로 닫는다 (뒤쪽 보스에 셀프탭). 뒷판 아래 Ø8 구멍은 외부로 전선을 뺄 때 쓴다.

램프 중심 높이는 바닥에서 43.5 / 118.5 / 193.5 mm. 램프면이 로봇 쪽(시뮬의 -y)을 향하게 세운다.

**배선 (Arduino Mega 2560, 박스 B1)**

| 핀 | 연결 | 비고 |
|---|---|---|
| D9 | 적 LED (+) | 직렬 저항: 10 mm LED 150 Ω |
| D10 | 황 LED (+) | 150 Ω |
| D11 | 녹 LED (+) | 100 Ω (Vf 3.2 V) |
| GND | LED (−) 공통 | |

- 램프당 10 mm LED 하나면 핀에 바로 단다 (20 mA). 5 mm 세 개를 쓰면 핀 전류(20 mA 권장)를 넘으니 NPN 트랜지스터(2N2222) 나 ULN2003 으로 끈다.
- 더 밝게: 램프마다 WS2812 8 mm 또는 5 V LED 스트립 3픽셀을 넣고 D6 하나로 제어한다. 카메라 판정(`detect_traffic_light`, 채도·명도 임계값)에는 이쪽이 안정적이다.
- 신호등 → 박스 전선 4가닥(GND + 3). 발판 홈 폭 8 mm 에 맞는 4심 케이블이면 된다.
- 점등 순서는 시뮬 `sim_traffic_light` 와 같이 적 → 황 → 녹, 녹색 5 초.

## 차단바 조립과 배선

```
                  허브 C3
   [꼬리 C6]═══╬═══[C4][C4][C4][C4][C4][C5]  ← 300 mm, 흑백 교대
               │ 서보 혼
          ┌────┴───┐ ← C1 기둥 꼭대기 포켓에 서보 (축이 도로와 나란, 몸통 세로)
          │        │
          │  속 빈 │ ← 서보선이 기둥 속으로 내려간다
          │  기둥  │
     ─────┴────────┴───── C2 발판 (밑면 홈 → 박스 쪽)
   도로 →                                            ← 박스 B1
```

1. 서보(SG90/MG90S)를 기둥 꼭대기 포켓에 **바깥에서** 밀어 넣는다. 탭이 기둥 면에 닿고 축이 바깥(+y)을 향한다. M2 ×8 나사 두 개로 탭을 고정(구멍 Ø1.8 셀프탭).
2. 서보선은 포켓 안쪽에서 기둥 속으로 떨어뜨려 바닥으로 뺀다. 발판을 쓰면 가운데 Ø10 구멍 → 밑면 홈 → 도로 반대쪽 가장자리로 나온다. 발판을 안 쓰면 기둥 아래 -y 면의 8×10 슬롯으로 뺀다.
3. 허브 C3: 아랫면 Ø21 홈에 둥근(십자) 혼을 앉히고, 45° 방향 구멍 4개에 M2 ×6 나사로 혼을 허브에 고정한다. 가운데 Ø6.5 구멍으로 드라이버를 넣어 혼 나사를 서보 축에 조인다. **먼저 서보를 0°(닫힘) 위치로 보내고** 바가 수평이 되는 각도로 혼을 끼운다 (스케치에 `c` 를 보내면 0° 에 선다).
4. 바 토막 C4 다섯 개와 끝 토막 C5 를 장부로 이어 허브 +x 소켓에 꽂는다. 소켓 쪽은 바가 힌지보다 45 mm 아래로 처지는 쪽(허브 소켓은 축 아래로 치우쳐 있다). 꼬리 C6 에 동전·너트를 넣고 반대쪽 소켓에 꽂는다.
5. 기둥을 발판 소켓에 세운다. 발판은 도로 쪽으로 100 mm, 반대쪽으로 60 mm 뻗어 있어 바가 수평이어도 넘어지지 않는다. 바닥(포맥스)에 양면테이프.

바를 내리면 바닥에서 155~205 mm 를 가린다. Burger 라이다(171 mm)가 바를 보고,
카메라는 줄무늬를 멀리서 본다(`level_crossing_mission` 이 쓰는 두 가지).

**센서 기둥** (바에서 6 cm 앞에 2번, 30~85 cm 앞에 1번; 시뮬 `SENSOR1_DISTANCE`)

- C7: E18-D80NK 적외선 반사 센서(M18). 기둥 Ø18.4 구멍에 넣고 양쪽 너트로 조인다. 축 높이 40 mm — Burger 의 바퀴·하판 높이라 검은 로봇도 잡힌다. 감도 볼륨을 도로 폭(30 cm)보다 조금 넓게 맞춘다. 로봇도 바닥도 검정이라 반사식은 거리가 짧아진다; 안 잡히면 아래 레이저로.
- C8: KY-008 레이저 모듈을 한 기둥에(헤드가 Ø6.4 구멍으로, PCB 는 뒤쪽 포켓), 건너편 기둥에 수광 모듈(ISO203 또는 5 mm 포토트랜지스터)을 넣어 도로를 가로지르는 **차광식**으로 쓴다. 가장 확실하다. 기둥 4개 필요.
- 센서선은 기둥 밑면 홈(6 mm)으로 뺀다.

**배선 (Arduino Mega 2560, 박스 B1)**

| 핀 | 연결 | 비고 |
|---|---|---|
| D9 | 서보 신호 (주황) | 5 V, GND. MG90S 권장 (금속 기어, 2.2 kg·cm) |
| D2 | 1번 센서 OUT | `INPUT_PULLUP`, 감지 시 LOW (E18: 검정선, NPN) |
| D3 | 2번 센서 OUT | 같음 |
| D7 | 레이저 VCC (차광식일 때) | 항상 켜 두려면 5 V 에 직결 |
| D8 | 부저 (선택) | 2번 센서 침범 알림 |
| D13 | 내장 LED | 바 내려감 표시 |
| 5 V / GND | 서보, 센서 ×2, 레이저 | E18: 갈색 5 V, 파랑 GND |

- 서보 전류 피크 ~0.5 A: 메가의 5 V 핀으로 하나는 돌아간다. USB 가 아니라 DC 잭 9 V 어댑터로 주면 안정적이다.
- 동작: 1번 LOW → 바 내림(서보 0°), 10 초(시뮬 `closed_duration`) 뒤 올림(90°). 내려간 동안 2번 LOW → 실패 표시(부저). 아래 스케치가 한다.
- 박스는 기둥 뒤(도로 반대쪽)에 두고, 발판 홈이 그쪽을 향한다. 센서선 2개 + 서보선 1개가 뒷벽 윗가장자리의 홈 3개로 들어온다.

## 아두이노 스케치 (firmware/)

`firmware/traffic_light/`, `firmware/level_crossing/` 를 Arduino IDE 나 arduino-cli 로
Mega 2560 에 올린다 (보드: Arduino Mega or Mega 2560). 핀 번호는 Uno 와 같아 Uno 에도 그대로 올라간다. 핀은 위 표와 같고, 시간은 시뮬 노드와 같다 (신호등 적 5·황 2·녹 5 초
반복, 전원 뒤 5 초는 꺼짐; 차단바 닫힘 10 초). 차단바는 Servo 라이브러리가 필요하다.

```bash
arduino-cli lib install Servo
arduino-cli compile --fqbn arduino:avr:mega firmware/level_crossing
arduino-cli upload  --fqbn arduino:avr:mega -p /dev/ttyACM0 firmware/level_crossing
```

시리얼 모니터(115200)로 손으로 움직일 수 있다:

| 스케치 | 키 | 동작 |
|---|---|---|
| 신호등 | `r` `y` `g` | 램프 강제 (카메라 임계값 맞출 때) |
| | `a` | 자동 순환 복귀 |
| 차단바 | `d` `u` | 바 내림 / 올림 |
| | `c` | 혼 조립 위치(0°, 센서 무시) |
| | `a` | 자동 복귀 |
| | `r` | 위반 표시 지움 |
| 둘 다 | `s` | 상태 출력 |

차단바 스케치는 바가 올라간 뒤 1번 센서가 2 초 동안 비어야 다시 무장한다. 바가
도로 쪽으로 올라가면 `ANGLE_CLOSED = 180, ANGLE_OPEN = 90` 으로 바꾼다. 서보는
1° 씩 15 ms 로 움직여 90° 에 약 1.4 초 걸린다 (바가 튀지 않게). 램프에 WS2812 를
넣었으면 `USE_WS2812 1`, 데이터선 D6, Adafruit NeoPixel 라이브러리.

## 컨트롤러 박스 B1/B2

Arduino Mega 2560 용 (117×66×32). 바닥 보스 6개(Ø2.6, M3 셀프탭)가 메가 구멍 위치와
같다. 짧은 쪽 벽에 USB-B 창과 DC 잭 창, 긴 쪽 뒷벽 윗가장자리에 8 mm 케이블 홈 3개.
뚜껑은 압입. Uno 는 왼쪽 보스 4개가 같은 자리라 그대로 들어간다 (오른쪽이 33 mm 남는다).

## 표지판

D1 받침(70×30 바닥, 12×12 기둥, 높이 130 + 장부 12)에 판을 꽂는다. 판 앞면에
0.8 mm 홈(폭 116)이 있고 `signs/` 의 얼굴을 라벨지에 300 dpi 로 출력해 붙인다.
`sign_sheet_A4.pdf` 를 **실제 크기(100 %)** 로 인쇄할 것. 판 바닥에서 중심까지
약 190 mm, 시뮬 텍스처의 판 위치와 같다.

| 표지판 | 판 | 코스 위치 (시뮬 `SIGNS`) |
|---|---|---|
| intersection | D4 삼각 | 갈림길 전 |
| left / right | D2 원 | 갈림길 섬 (하나만 세움, 당일 공개) |
| construction | D4 삼각 | 공사 구간 전 |
| parking | D5 사각 | 주차장 전 |
| tunnel | D4 삼각 | 터널 입구 |
| stop | D3 팔각 | 정지선 |

## 공사 기둥 E, 터널 장애물 F

공사 기둥은 90×234, 높이 400 (시뮬 `CONSTRUCTION_HEIGHT`). 220 mm 베드에 들어가게
띠 하나를 반쪽 트레이 2개(E1)로 나누고 E2 슬리브로 잇는다. 트레이 밑의 6 mm
플러그가 아래 띠에 들어가 쌓인다. 맨 아래 띠에 모래 주머니나 물병을 넣으면 안
넘어진다. 띠 4개 = E1 ×8 + E2 ×4, 맨 위 E3 ×2.

터널 장애물은 시뮬 `TUNNEL_OBSTACLES` 와 같은 상자·원기둥 껍데기(높이 200). 뒤집어
놓고 출력, 안이 비어 있다. 300 mm 상자는 150 짜리 두 개를 붙인다.

## 시뮬과 다른 점

| 항목 | 시뮬 | 실물 | 이유 |
|---|---|---|---|
